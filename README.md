# Personal Profile Webpage

A responsive personal profile webpage for Vedang Abhay Nirgude, created using HTML and CSS.

## Features

- Profile introduction and photograph placeholder
- About Me section
- Educational information
- Skills and interests
- Email and social-media links
- Navigation links to each section
- Responsive layout for desktop, tablet, and mobile screens
- Keyboard-accessible navigation and reduced-motion support

## Technologies Used

- HTML5 — structures the webpage and its content
- CSS3 — controls colours, fonts, spacing, borders, and layout

No JavaScript, frameworks, or installation is required.

## Project Files

| File | Description |
|------|-------------|
| `index.html` | Contains the webpage structure and content |
| `style.css` | Contains styling and responsive layout rules |
| `README.md` | Provides project information and instructions |

## How to Run

1. Download `index.html` and `style.css`.
2. Keep both files in the same folder.
3. Open `index.html` in a web browser.

## Customisation

Edit `index.html` to:

- Update the name, introduction, and biography.
- Replace the photograph placeholder with your own image.
- Enter your degree, institution, and study dates.
- Update the sample skills and interests.
- Replace `yourname@example.com` in both the email link and its displayed text.
- Replace the GitHub and LinkedIn homepage links with your profile URLs.
- Remove placeholder instructions after adding your details.

To use a local photograph, save it as `profile.jpg` in the same folder and change the profile image's `src` to `profile.jpg`. Update its `alt` text to describe your photograph.

Edit `style.css` to change the colours, fonts, spacing, and layout. The main colour settings are defined near the top of the file.
